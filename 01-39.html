🏛️ 華爾街 8 大量化風控模型 (西方體系)

① 數學家 (拉普拉斯平滑均值)
P = (Hits + 1) / (N + 2)
處理稀疏數據，避免機率歸零，提供平穩的基礎期望值定錨。
② 資金家 (凱利公式)
f* = p - [ (1 - p) / b ]
若 f* 為正數代表具備長期投資優勢；負數則強制觀望。
③ 贏家 (馬可夫轉移狀態)
P(Hit|Miss_k)
精準捕捉該號碼在特定遺漏狀態的爆發動能。
④ 銀行家 (Z-Score 乖離率)
Z = (CurrentMiss - μ) / σ
Z > 0 代表處於欠收期，有利於回歸。Z < 0 代表開出過密。
⑤ 精算家 (最大回撤 Drawdown)
MDD = Max(Peak - CurrentEquity)
越低代表抗震性越強，歷史經歷的資金連續失血最少。
⑥ 莊家 (單注期望值 EV)
EV = (P × Profit) - ((1-P) × Cost)
EV 為正才代表這是一筆長線穩賺不賠的交易。
⑦ 操盤手 (RSI 相對強弱指標)
RSI = 100 - 100 / (1 + RS)
RSI > 50 顯示具備向上強勢動能。
⑧ 分析師 (Sharpe 夏普比率)
Sharpe = AvgReturn / StdDev
Sharpe > 0 代表你承擔的風險能換取超額報酬。

⛩️ 東方 10 大量化收斂模型 (玄學與數學交集)

⑨ 蒙地卡羅動能 (均線交叉)
IF (Prob_10 > Prob_All) -> Score+
當短期勝率強勢穿越長期總勝率，視為主力進駐。
⑩ 傅立葉頻譜 (規律共振)
Check Symmetrical Miss Gaps
若近期遺漏期數呈現對稱，判定為規律共振點。
⑪ 貝氏條件機率 (生存者偏差)
P = 1 / (Total(Miss > Current) + 1)
次數越少，代表該號碼越接近其生存極限。
⑫ 混沌極限理論
Trigger IF |Z-Score| > 1.5
當 Z-Score 突破臨界值，發生反轉的機率呈非線性暴增。
⑬ 卜瓦松絕境反轉
CurrentMiss >= (MaxMiss * 0.8)
遺漏期數逼近歷史最高紀錄 80% 時，啟動強力反彈加分。
⑭ 費波那契數列 (黃金分割)
Miss ∈ [1, 2, 3, 5, 8, 13, 21, 34]
大自然的黃金密碼，常作為神秘的支撐位判定。
⑮ 高斯回歸偏態
Skew = Prob_10 - Prob_30
正偏態代表近期爆發力度遠超波段均值。
⑯ 馬可夫歷史動能 (過熱熔斷)
HotState Prob Check / Circuit Breaker
以歷史真實數據檢測「過熱連開」的延續率。若近5期開出3次以上則直接啟動強制冷卻熔斷機制。
⑰ 深度神經擬合 (複合指標)
Weighted Σ (M1, M3, Prob30)
多層次權重融合，作為系統防禦雜訊的壓艙石。
⑱ 一目均衡表 (Ichimoku 突破)
CurrentMiss > Kijun-Sen
目前遺漏值強勢升破基準線雲層時，進入佈局區。

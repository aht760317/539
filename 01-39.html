🏛️ 華爾街 6 大量化風控模型 (西方體系)

① 數學家 (拉普拉斯平滑均值)
P = (Hits + 1) / (N + 2)
傳統機率易受極端值干擾。導入 Laplace Smoothing 處理稀疏數據，避免機率歸零，提供最平穩的基礎期望值定錨。
② 資金家 (凱利公式)
f* = p - [ (1 - p) / b ]
華爾街倉位管理聖經。b 為賠率(4.3)，p 為勝率。當算出的 f* 為正數，代表此號碼具備長期投資優勢；若為負數則強制觀望。
③ 贏家 (馬可夫轉移狀態)
P(Hit|Miss_k)
不看總勝率，只看「在目前槓了 K 期的狀態下，歷史上反轉開出的機率」。精準捕捉該號碼在特定遺漏狀態的爆發動能。
④ 銀行家 (Z-Score 乖離率)
Z = (CurrentMiss - μ) / σ
測量當前遺漏期數偏離歷史平均(μ)有幾個標準差(σ)。Z > 0 代表處於欠收期，有利於回歸。Z < 0 則代表開出過密。
⑤ 精算家 (最大回撤 Drawdown)
MDD = Max(Peak - CurrentEquity)
模擬單壓此號碼的歷史淨值曲線。MDD 代表歷史上經歷過最慘烈的資金連續失血。越低代表抗震性越強。
⑥ 莊家 (單注期望值 EV)
EV = (P × Profit) - ((1-P) × Cost)
賭場與莊家賴以生存的核心指標。將近 30 期勝率代入賠率計算，EV 為正才代表這是一筆長線穩賺不賠的交易。

⛩️ 東方 9 大量化收斂模型 (玄學與數學交集)

⑦ 蒙地卡羅動能 (均線黃金交叉)
IF (Prob_10 > Prob_All) -> Score+
動量投資派。當短期(10期)勝率強勢穿越長期總勝率，視為籌碼集中、主力進駐，賦予高額動能分數。
⑧ 傅立葉頻譜 (規律共振)
Check Symmetrical Miss Gaps
分析號碼開出的「頻率」。若近期遺漏期數呈現對稱（如：隔3期、隔5期、隔3期），判定為主力畫線的共振點。
⑨ 貝氏條件機率 (生存者偏差)
P = 1 / (Total(Miss > Current) + 1)
在歷史紀錄中，有多少次槓得比現在還久？次數越少，代表該號碼越接近其「生存極限」，隨時會爆發。
⑩ 混沌極限理論
Trigger IF |Z-Score| > 1.5
市場常態屬隨機漫步，但當 Z-Score 突破臨界值，系統將進入「混沌邊緣」，此時發生反轉的機率呈現非線性暴增。
⑪ 卜瓦松絕境反轉
CurrentMiss >= (MaxMiss * 0.8)
專抓極端罕見事件。當號碼遺漏期數逼近歷史最高遺漏紀錄的 80% 時，啟動強力反彈加分。
⑫ 費波那契數列 (黃金分割)
Miss ∈ [1, 2, 3, 5, 8, 13, 21, 34]
大自然的黃金密碼。許多時間序列的反轉點，容易落在費波那契數列的天數上，作為神秘的支撐位判定。
⑬ 高斯回歸偏態
Skew = Prob_10 - Prob_30
測量機率分佈的傾斜度。正偏態代表近期爆發力度遠超波段均值，是抓取連莊或短線強勢股的核心。
⑭ 馬可夫隱藏狀態 (HMM)
Detect Latent State (Overheated)
防追高機制。即使勝率再高，若判定目前處於「過熱崩盤前夕（10期內狂開3次以上）」，將嚴格扣分打入冷宮。
⑮ 深度神經擬合 (複合指標)
Weighted Σ (M1, M3, Prob30)
將拉普拉斯定錨、馬可夫狀態與波段均值，進行多層次權重融合，作為系統防禦雜訊的最終壓艙石。
